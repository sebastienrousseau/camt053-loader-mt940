# camt053-loader-mt940 v0.0.16

Suite release aligned to the camt053 suite v0.0.16 line. No functional
changes in this package.

## What changed

- **Version aligned to the suite.** Every package in the camt053 suite
  ships the same number, so there is no compatibility table to consult.
  `camt053.suite` records the rule and a daily job checks it against
  PyPI.

- **The `camt053` floor moves to `>=0.0.16`,** from `>=0.0.6` — a
  bound that had not been revisited in nine releases. It still resolved,
  so nothing ever complained about it.

- **A version-sync test.** `pyproject.toml` and `__init__.py` state
  the version independently and nothing compared them. The first attempt
  at this release landed `__init__.py` at 0.0.16 against a
  `pyproject.toml` still on 0.0.14, and every check passed.

## Compatibility

No API change. Requires `camt053 >= 0.0.16, < 1`.
