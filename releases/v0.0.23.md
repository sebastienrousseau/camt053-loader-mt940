# camt053-loader-mt940 v0.0.23

## Highlights ⭐️

* **One statement per `:20:`**: a file carrying several MT940 statements now returns one `Statement` each, with its own account, balances and entries. It used to merge them under the last account in the file.
* **In lockstep with camt053 0.0.23**: the suite's six packages are back on one version, and this package requires `camt053` 0.0.20 or newer.
* **Verifiable releases**: every CI and release action is pinned by commit, tools install from hash-pinned files and are audited with `pip-audit`, and each release carries a CycloneDX SBOM, SLSA provenance and sigstore signatures.
* **Licensing and docs to the family standard**: every file is `reuse lint` clean under `Apache-2.0 OR MIT`, and the README follows the shared template with a rendered demo.
