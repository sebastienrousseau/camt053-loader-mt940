# camt053-loader-mt940 v0.0.26

## Highlights ⭐️

* **In lockstep with camt053 0.0.26**: this package requires `camt053` 0.0.26 or newer, below 1, so every member of the suite ships and resolves the same version.
* **A smaller install**: camt053 0.0.26 keeps its REST stack behind `camt053[api]`, so installing this loader no longer brings fastapi, uvicorn or the packages they need. `parse_mt940` returns the same `ParsedDocument` for the same input as 0.0.25.
